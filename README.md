# Logistics Data Analytics Internship Project

This repository contains my four-week Logistics Data Analyst internship project completed as part of the YuvaIntern program.

The project follows a step-by-step analytics workflow, starting with problem definition and strategic planning, followed by data cleaning, exploratory data analysis, visualization, predictive modeling and logistics optimization.

## Project Progression

| Week | Topic | Main Work |
|---|---|---|
| Week 1 | Strategic Planning and Data Exploration | Defined the logistics problem, KPIs, data-science approach and analytical roadmap |
| Week 2 | Data Collection, Cleaning and Preprocessing | Prepared a reproducible Python preprocessing workflow for logistics data |
| Week 3 | Advanced Data Analysis and Visualization | Performed EDA and created logistics performance visualizations using a simulated dataset |
| Week 4 | Predictive Modeling and Optimization | Compared regression models for delivery-time prediction and proposed optimization strategies |

## Project Theme

The main business problem throughout the internship is **delivery performance in logistics**. The analysis focuses on delivery time, late deliveries, transportation cost, shipping mode, distance, shipment volume and regional performance.

Week 1 and Week 2 use the public **DataCo Smart Supply Chain for Big Data Analysis** dataset as the reference dataset. For Week 3 and Week 4, I use a controlled hypothetical logistics dataset, as permitted by the assignment, so that the EDA and predictive-modeling workflow can be reproduced consistently.
